# AI-Workflow-Automated-Social-Media-Content-Generation-with-n8n

In this project, I build an Automated Social Media Content Generation Workflow using n8n that transforms news articles into engaging social media content.

AI workflows, which are automated steps that use AI to complete tasks like creating content, analyzing data, and executing tasks automatically without needing human involvement.

Have API keys and credentials :
        > Google Gemini (API Key)
        > Google Sheets
        > LinkedIn

In the busy days staying active in social media and posting content makes the life a bit hard and exhausted that where this project comes into place where you don't have to do any sort of research before posting blogs or content in social media all the process will be done using the AI integrated in the workflow which summarize the content and make it ready to postable content.
